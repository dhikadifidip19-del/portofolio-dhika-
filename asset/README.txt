FOLDER GAMBAR PRESTASI & PROYEK

1. GAMBAR PRESTASI:
Taruh gambar asli Anda di folder ini, misalnya:
prestasi1.png
prestasi2.jpg
prestasi3.jpeg
prestasi4.png
Nama file harus huruf kecil, tanpa spasi, tanpa nol di depan nomor.
Boleh mencampur PNG, JPG, dan JPEG. Default memeriksa nomor 1 sampai 100.
Untuk lebih banyak gambar, ubah prestasiMax di config.js.
Halaman prestasi.html mendeteksi gambar tanpa perlu mengedit HTML.

2. GAMBAR PROYEK (PROJECT):
Anda juga bisa menaruh gambar untuk bagian project di sini dengan nama file:
project1.png (atau project1.jpg / proyek1.png) -> untuk Proyek 1
project2.png (atau project2.jpg / proyek2.png) -> untuk Proyek 2
project3.png (atau project3.jpg / proyek3.png) -> untuk Proyek 3
project4.png (atau project4.jpg / proyek4.png) -> untuk Proyek 4

Website akan otomatis menampilkan gambar tersebut pada kartu proyek dan jendela pop-up detail!
Selain cara ini, Anda juga bisa mengatur link gambar proyek lewat file `config.js` (pada bagian `projectImages`) atau langsung di `index.html`.

Folder assets (dengan s) tetap dipakai untuk CV dan favicon; jangan dihapus.
