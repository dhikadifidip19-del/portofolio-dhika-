# Aset tema desa pegunungan

Aset asli dibuat dengan built-in Imagegen untuk portofolio ini. Bukan foto lokasi nyata atau dokumentasi pribadi Dhika.

- `desa-pegunungan.png`: lanskap desa pegunungan, digunakan di halaman utama dan prestasi.
- `burung.png`: siluet burung layang-layang transparan, dianimasikan melalui CSS.

Prompt lanskap: Original cinematic Indonesian mountain village landscape; lush terraced rice fields, terracotta village lower right, dramatic green-blue volcanic peaks, pale blue sky, morning golden light, atmospheric mist, refined painterly texture, quiet shaded left midground for text overlay; no lettering, logos, UI, people, birds, or watermark.

Prompt burung: Single swallow bird silhouette in flight, wings spread wide in an elegant shallow V, viewed from below at slight diagonal, dark forest-green / near-black, recognizable forked tail, centered on genuinely transparent alpha background; no text, landscape, shadow, or other birds. Readable at small sizes.

Animasi: CSS flight + wingbeat, kabut/awan tipis, cahaya, partikel, panel mengambang, serta JavaScript untuk parallax ringan, reveal, tema dan jeda. File gambar berada di paket ini sehingga tampilan tidak bergantung pada URL gambar eksternal.
